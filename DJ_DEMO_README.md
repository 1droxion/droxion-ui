# DJ Swagg Nation — Cinematic Website Demo

A responsive DJ showcase and booking-calendar concept, optimized for phone and desktop.

## Features
- Cinematic concert-inspired homepage and animated accents
- Event packages and editable starting prices
- Availability calendar showing open and busy dates
- Booking request form
- DJ dashboard with pending inquiries, confirmed bookings, completed events, and blocked dates
- Upcoming public shows, with private events kept off the public listing
- Mobile quick-booking toolbar and reduced-motion support

## Run the demo
Open `index.html` in Chrome or Edge. No install or build step required.
Use **DJ Dashboard** in the navigation to update sample data. On mobile, use the menu to find the dashboard.

## IMPORTANT — demo limitations
This is a **static, browser-only demonstration**. Sample data and booking changes are stored only in your local browser. Requests are not emailed or synchronized across different devices. The dashboard has no authentication. Do not put it into live customer service or collect genuine client data until a secure backend, authentication, notifications, validation, and operational processes are implemented.

The hero photo is a **sample licensed Unsplash photo**, not an image of DJ Swagg Nation: Simon Kessler, https://unsplash.com/photos/KyOYdE4sNk4 . Replace with approved DJ photos for production.
The logo is based on the client reference screenshot and should be confirmed with the DJ before public launch.
